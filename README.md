# MusicJam v2

FYI: Разработчики, этот репозиторий теперь является публичным, поэтому прошу особенно тщательно следить за отсутствием секретов и иных чувствительных данных в коде. Репозиторий открылся для возможности бесплатно запускать сценарии CI CD на мощностях GitHub Actions

## Локальный запуск для разработки

1. Перейти на нужную ветку репозитория
2. Проверить, что .env заполнен в соответствии с .env.example (Если же .env нет вовсе, его нужно создать и заполнить. P.S. Длина JWT_SECRET - минимум 32 байта)
3. Из корня репозитория выполнить команду `docker compose up --build -d`
4. По завершении сборки открыть в браузере http://localhost:5000
