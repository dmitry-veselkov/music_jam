# music_jam
MusicJam version 2.0

## Локальный запуск для разработки

0. Один раз в жизни запустить в PowerShell от имени админа `dotnet dev-certs https --trust`, чтобы заработал HTTPS (P.S. TLS временно отключен, veselkov.d вернет его, когда будет настраивать nginx и деплоить приложение, для локального запуска отсутствие шифрования не критично)
1. Перейти на нужную ветку репозитория
3. Из корня репозитория выполнить команду `docker compose up --build -d`
4. По завершении сборки открыть в браузере http://localhost:5000
