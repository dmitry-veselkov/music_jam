# music_jam
MusicJam version 2.0

## Локальный запуск

1. Склонировать нужную ветку с GitHub
2. Проверить, что localhost.musicjam.fun прописан в hosts. Если его там нет - прописать, указав ip 127.0.0.1
3. Запустить 3 проекта: ApiGateway, Studio, Runtime (в Rider можно настроить мульти запуск, чтобы поднимать сразу несколько проектов)
4. Отправлять запросы на http://localhost.musicjam.fun:5000 (на этом порту работает Gateway, он сам определит на какой микросервис перенаправить ваш запрос)
